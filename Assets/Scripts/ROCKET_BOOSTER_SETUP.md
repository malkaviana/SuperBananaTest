# Настройка бустера "Ракета"

## Описание

Бустер "Ракета" позволяет уничтожить случайный элемент на поле и до 2 дополнительных элементов в соседних полках (сверху и снизу от целевой полки).

## Настройка в сцене

### 1. RocketBoosterController

1. В иерархии найдите объект в **Canvas_Dynamic_Boosters** (или создайте новый GameObject).
2. Добавьте компонент **RocketBoosterController**.
3. В инспекторе задайте:
   - **Button** — кнопка бустера (Button компонент). Если не задана, ищется на том же объекте.
   - **Button Rect** — RectTransform кнопки (для вычисления стартовой позиции ракеты). Если не задана, берётся с того же объекта.
   - **Rocket Projectile Prefab** — префаб ракеты (должен иметь компонент **RocketProjectile** или он добавится автоматически).
   - **Z Depth** — глубина Z для конвертации UI координат в мировые (обычно 0 или -10).
   - **Fly Time** — время полёта ракеты в секундах (по умолчанию 1).
   - **Arc Height** — высота дуги полёта (по умолчанию 2).

### 2. RocketProjectile (префаб)

Создайте префаб ракеты:

1. Создайте **GameObject** (например `RocketProjectile`).
2. Добавьте компонент **RocketProjectile**:
   - **Explosion Vfx Prefab** — префаб VFX взрыва (спавнится при достижении цели).
   - **Explosion Sfx** — звук взрыва (AudioClip).
   - **Rotation Speed** — скорость поворота ракеты по направлению движения (по умолчанию 10).
3. Добавьте **ParticleSystem** (компонент добавится автоматически через `RequireComponent`):
   - Настраивается автоматически в коде для создания следа ракеты.
   - Можно дополнительно настроить в инспекторе: цвет, размер, lifetime частиц.
4. Добавьте визуал ракеты (SpriteRenderer с спрайтом ракеты). **Важно:** спрайт должен быть ориентирован вправо (носом вправо), так как ракета поворачивается по направлению движения.
5. Сохраните как префаб и назначьте его в **RocketBoosterController → Rocket Projectile Prefab**.

### 3. Связь с GameManager

**RocketBoosterController** автоматически находит **RandomShelfPlacer** в сцене через `FindFirstObjectByType`. Убедитесь, что:
- В сцене есть объект с **RandomShelfPlacer**.
- В **RandomShelfPlacer** задан массив **Shelves** (полки).

## Логика работы

1. **При нажатии кнопки:**
   - Кнопка блокируется (`interactable = false`), устанавливается флаг `busy`.
   - Собирается список всех слотов, где есть элемент (`slot.HasItem() == true`) и элемент не заблокирован цепью (`item.IsChained == false`).
   - Выбирается случайный целевой слот.

2. **Запуск ракеты:**
   - Вычисляется стартовая позиция из UI координат кнопки (конвертация через Camera.main).
   - Создаётся экземпляр **RocketProjectile** в стартовой позиции.
   - Ракета инициализируется: `Initialize(startPos, targetPos, flyTime, arcHeight, callback)`.

3. **Полёт ракеты:**
   - Ракета движется по дуге: `Lerp(start, target, t) + sin(t * π) * arcHeight`.
   - Поворачивается **носом вперёд** по направлению движения (угол вычисляется из разницы позиций с учётом дуги).
   - **ParticleSystem** создаёт след из частиц (настраивается автоматически, можно изменить в инспекторе).

4. **При достижении цели:**
   - Спавнится **ExplosionVfxPrefab** в позиции цели.
   - Проигрывается **ExplosionSfx**.
   - Вызывается callback `OnImpact`.

5. **В OnImpact:**
   - Уничтожается целевой элемент через `targetItem.DestroyItem()`.
   - Определяются `shelfIndex` и `slotIndex` цели.
   - Проверяются соседние полки (`shelfIndex - 1` и `shelfIndex + 1`):
     - Сначала проверяется слот с тем же `slotIndex`.
     - Если он пуст или заблокирован — ищется ближайший занятый слот в той же полке.
     - Если найден элемент и он не заблокирован (`!IsChained`) — уничтожается.
   - Максимум уничтожается **2 дополнительных элемента** (по одному в каждой соседней полке).

6. **После завершения:**
   - Снимается флаг `busy`.
   - Кнопка разблокируется (`interactable = true`).

## Методы, добавленные в существующие классы

- **ElementController.DestroyItem()** — уничтожает элемент и очищает слот.
- **ElementController.IsChained** — свойство, проверяющее, заблокирован ли элемент цепью (через `CurrentSlot.IsBlocked`).
- **ShelfSlot.HasItem()** — проверяет, есть ли элемент в слоте и не заблокирован ли он.
- **RandomShelfPlacer.Shelves** — публичное свойство для доступа к массиву полок из бустеров.

## Примечания

- Если в соседней полке нет подходящих элементов (все заблокированы или пусты), эта полка пропускается.
- Ракета уничтожается через 0.1 секунды после достижения цели (чтобы успел проиграться звук).
- VFX взрыва уничтожается через 3 секунды после спавна.
