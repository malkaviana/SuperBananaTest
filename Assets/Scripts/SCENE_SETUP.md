# Настройка сцены — SuperBanana 2D Puzzle

## 1. Конфиг игры

1. В Project: **ПКМ → Create → SuperBanana → Game Config**. Сохраните как `GameConfig` (например в `Assets/Resources/` или `Assets/Settings/`).
2. В инспекторе задайте:
   - **Timer Seconds** — 120 (2 минуты).
   - **Base Points Per Match** — 10.
   - **Combo Bonus Per Step** — 10 (формула очков: 10 + (1 + combo) × 10).
   - **Matches To Break Chain** — 2.
   - **Sound Match** — аудиоклип (например `mixkit-fairy-arcade-sparkle-866`).
   - **Sound Chain Tap** — аудиоклип (например `mixkit-quick-lock-sound-2854`).
   - **Sound Chain Break** — аудиоклип (можно тот же или другой).
   - **Match Vfx Prefab** — префаб VFX при совпадении тройки (опционально).
   - **Chain Break Vfx Prefab** — префаб `BrokenChain_VFX`.

---

## 2. Менеджер игры и ввод

1. Создайте пустой **GameObject** (например `GameManager`).
2. Добавьте компонент **GameManager**.
3. В поле **Config** перетащите ваш asset **GameConfig** (или положите конфиг в `Resources/GameConfig` и не заполняйте поле).
4. На **Main Camera** (или на этот же объект) добавьте **GameplayInput**:
   - **Raycast Camera** — камера сцены (если пусто, подставится `Camera.main`).
   - **Use Pointer Events Only** — выключен, если слоты с **Collider2D**; включен, если слоты только UI и клики идут через EventSystem.

---

## 3. Полки (контейнеры) и слоты

### Полка (Shelf)

1. На корне префаба/объекта **полки** (например `Shelf_0`) добавьте **ShelfController**.
2. **Config** можно не задавать — подтянется из GameManager.
3. **Match Vfx Spawn Point** — опционально: Transform, в какой точке спавнить VFX при совпадении (если пусто — в `transform` полки).
4. Слоты подтянутся автоматически по дочерним объектам со **ShelfSlot** (см. ниже).

### Слоты

Для каждой **ячейки** полки:

1. Создайте дочерний **GameObject** под полкой (например `Slot_0`, `Slot_1`, …).
2. Разместите его в нужной позиции (куда будут ставиться элементы).
3. Добавьте компонент **ShelfSlot**:
   - **Shelf** — заполнится автоматически из родителя (ShelfController) или перетащите полку вручную.
   - Блокировка цепью настраивается на **полке** (см. п. 4): цепь блокирует всю полку (все 3 слота).
4. Для **определения ячейки под курсором при отпускании** у слота должен быть **Collider2D** (например **Box Collider 2D**): размер и позиция по области ячейки.
5. Элементы на полке: поместите префабы элементов (**Element_Banana** и т.д.) **как дочерние объекты нужного слота**. У каждого элемента должен быть **Collider2D** (или он добавится автоматически через **ElementController**), чтобы тап срабатывал по предмету. При старте **ShelfController** сам найдёт у слота дочерний **ElementController** и зарегистрирует элемент в слоте.

Итоговая иерархия примера (цепь настраивается на полке или в ChainController):

```
Shelf_0 (ShelfController, Chain Blocker = Chain_1 — опционально)
├── Slot_0 (ShelfSlot, BoxCollider2D)
│   └── Element_Banana (ElementController)
├── Slot_1 (ShelfSlot, BoxCollider2D)
├── Slot_2 (ShelfSlot, BoxCollider2D)
```

### Рандомное размещение в начале раунда (опционально)

Если нужно заполнять полки автоматически при старте уровня:

1. Создайте пустой **GameObject** (например `LevelSetup`).
2. Добавьте компонент **Random Shelf Placer**.
3. В **Shelves** перетащите все полки (**ShelfController**), которые нужно заполнить (нужно минимум 10 полок по 3 слота = 30 слотов).
4. В **Element Prefabs By Type** задайте массив из **5** префабов в порядке enum: `[0] Banana`, `[1] CoffeeCup`, `[2] Coral`, `[3] FlipFlop`, `[4] Snack`.
5. **Sets Per Type** — по умолчанию 2 (два набора по три = 6 элементов каждого типа, всего 30 элементов).

При **Start** скрипт очистит слоты, сгенерирует случайный набор (по 6 каждого типа), переставит типы так, чтобы в одной полке не было трёх одинаковых подряд, и создаст элементы в слотах. Элементы, расставленные вручную в сцене, будут удалены и заменены этим набором.

## 4. Цепь (блокировщик полки)

Цепь блокирует **целую полку** — все 3 слота этой полки.

1. Выберите в сцене **корневой объект префаба Chain** (тот, у которого висит **Animator** с параметрами **Tap** и **Break**).
2. Добавьте компонент **ChainController**:
   - **Audio Source** — опционально; если пусто, создаётся свой.
   - **Blocked Shelf** — перетащите сюда **ShelfController** (полку), которую эта цепь блокирует. Все слоты этой полки будут заблокированы.
3. Опционально на самой **полке** (ShelfController) можно задать **Chain Blocker** — перетащить сюда эту цепь (для наглядности в инспекторе); при наличии **Blocked Shelf** в цепи связь полка↔цепь установится автоматически в Awake.

Поведение:

- Пока цепь «жива», **все слоты** этой полки считаются заблокированными; тап по любому из них или по цепи вызывает **Tap** (анимация + звук).
- После **2 уничтоженных троек** (в любых полках) цепь проигрывает **Break** (анимация + VFX + звук), полка разблокируется.

### Animation Controller цепи (Chain 2.controller)

Скрипт **ChainController** вызывает `SetTrigger("Tap")` и `SetTrigger("Break")`. В аниматоре нужны:

- **Параметры** (тип **Trigger**): **Tap**, **Break**.
- **Состояния**: например **ChainShaking** (тряска при тапе), **ChainBreaking** (разрыв).
- **Переходы**:
  - **Any State → ChainShaking**, условие **Tap** — при каждом тапе по цепи проигрывается тряска (добавлено в контроллер).
  - **Entry → ChainShaking** — стартовое состояние (Default State = ChainShaking).
  - **ChainShaking → ChainBreaking**, условие **Break** — при разрыве после 2 троек.
  - **Entry → ChainBreaking**, условие **Break** — опционально, если разрыв может вызваться до первого тапа.

Параметры должны быть именно **Trigger**, не Bool — иначе `SetTrigger` в коде не будет корректно переключать анимации.

## 5. Элементы (префабы)

На каждом префабе элемента (**Element_Banana**, **Element_CoffeeCup**, **Element_Coral**, **Element_FlipFlop**, **Element_Snack**):

1. Добавьте компонент **ElementController** (при отсутствии **Collider2D** он добавится в runtime для тапа по предмету).
2. В инспекторе выберите **Type** соответственно (Banana, CoffeeCup, Coral, FlipFlop, Snack). Если оставить по умолчанию, тип попытается подставиться по имени объекта в **OnValidate**.

Элементы должны лежать **дочерними к слоту** (см. п. 3). Перемещение: **тап по предмету** → удержание и перенос → **отпускание над пустой ячейкой** (предмет ставится туда) или в другом месте (возврат на место). При захвате и переносе масштаб предмета 1.2 (настраивается в **GameplayInput** → **Drag Scale**).

---

## 6. UI

- **Timer**  
  На корень префаба Timer добавьте **TimerUI**. Поле **Label** — дочерний TMP (например `TimeRemider`); если не задано, подставится первый `TMP_Text` в детях.

- **StarCounter (счётчик очков)**  
  На корень добавьте **ScoreUI**. **Label** — дочерний TMP (например `StarAmount`).

- **ComboCounter**  
  На корень добавьте **ComboUI**. **Label** — дочерний TMP (например `ComboText`). **Format** — по умолчанию `"Combo x {0}"`.

После этого очки, комбо и таймер будут браться из **GameManager** и обновляться по событиям.

## 7. Краткий чеклист

| Объект | Компоненты | Что задать |
|--------|------------|------------|
| GameConfig (asset) | — | Таймер 120, очки, звуки, VFX префабы |
| GameManager (GO) | GameManager | Config = GameConfig |
| Main Camera | GameplayInput | Raycast Camera (опционально) |
| Полка | ShelfController | Match Vfx Spawn Point (опционально) |
| Каждый слот полки | ShelfSlot + Collider2D | — |
| Полка (если под цепью) | ShelfController | Chain Blocker = цепь (опционально, см. п. 4) |
| Цепь (root) | ChainController | Blocked Shelf = полка (ShelfController) с 3 слотами |
| Элементы (префабы) | ElementController | Type |
| Timer | TimerUI | Label (TMP) |
| StarCounter | ScoreUI | Label (TMP) |
| ComboCounter | ComboUI | Label (TMP), Format |

## 8. Логика (кратко)

- **Перенос предмета:** тап по **предмету** (элементу) — захват; пока кнопка удержана, предмет следует за курсором, масштаб 1.2. При **отпускании**: если под курсором **пустая ячейка** — предмет ставится в неё; иначе возвращается в исходный слот. Тап по предмету в заблокированной ячейке воспроизводит анимацию/звук цепи.
- **Совпадение:** после каждого переноса проверяются слоты полки, куда поставили элемент: если в одной полке есть **3+ элемента одного типа**, они удаляются, играется VFX и звук, **GameManager** начисляет очки и увеличивает комбо.
- **Комбо:** если в предыдущем ходу уже была тройка и в текущем снова — комбо +1; очки за тройку: `10 + (1 + combo) × 10`. Если ход без тройки — комбо сбрасывается.
- **Цепь:** тап по заблокированному слоту/цепи → анимация Tap + звук. После 2 троек по сцене — анимация Break + VFX + звук, слот разблокируется.
- **Таймер:** обратный отсчёт 2:00 с начала уровня; по окончании вызывается **OnTimerEnd** (подписка при необходимости — экран результата и т.д.).
